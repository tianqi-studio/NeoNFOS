# NeoNFOS
这是一个用turbowarp制作的操作系统，它是NFOS的继任者

注意：它现在只是开发状态

版本号规则：

我们使用大版本.小版本.开发阶段(仅内部使用，不会对外公开)

我们只会在每个大版本(或更改较大的小版本)发布适用于所有平台的程序，小版本(不一定每个)只会有html的预览版。

⬇如何下载：<br/>如果你是windows用户，那么下载结尾为windows的。(不支持32位)<br/>如果你是macOS用户，那么下载结尾为macos的。<br/>如果你是linux用户，那么下载结尾为linux的。(不支持32位)

✅如何安装：<br/>解压压缩包(要是你连这个都不会嘛。。。)，当然，无需scratch。

如果你是windows，运行文件夹内后缀为exe的文件。<br/>如果你是macOS，详见下方<br/>由于 macOS 的限制，运行此应用程序需要一些手动操作。<br/><br/>在 macOS 15 及更高版本上运行此应用程序的方法：<br/>1) 双击应用程序文件（与本文档在同一文件夹中的 packaged-project），当出现警告时按“完成”<br/>2) 打开 macOS 系统设置<br/>3) 进入“隐私与安全”部分<br/>4) 滚动到最底部<br/>5) 在“为了保护您的 Mac，封锁了 packaged-project”旁，按“仍要打开”<br/>6) 在弹出的提示中，按“仍要打开”<br/><br/>在 macOS 14 及更早版本上运行此应用程序的方法：<br/>1) 按住 Control 键点击应用程序文件（与本文档在同一文件夹中的 packaged-project），选择“打开”<br/>2) 如果出现警告，如果有“打开”选项，请选择“打开”<br/>3) 如果出现警告但没有“打开”选项，按“取消”，然后从第 1 步重新操作。第二次出现警告时，打开按钮将会出现。<br/><br/>完成这些步骤后，应用程序应该可以正常运行而不会出现更多警告。你可以随意将应用程序拖到你的“应用程序”文件夹中。（此段为机翻，可能会有错误）<br/>至于linux我也不知道。
